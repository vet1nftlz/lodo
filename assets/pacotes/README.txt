IMAGENS DOS PACOTES

Coloque aqui os PNGs usados no inventario de pacotes.

O nome do arquivo deve ser exatamente a chave do pacote em config.py:

basico.png       -> pacote "basico"
premium.png      -> pacote "premium"
booster.png      -> pacote "booster"
pro.png          -> pacote "pro"
icon.png         -> pacote "icon"

Para um novo pacote:
"meu_pacote": {...}
-> assets/pacotes/meu_pacote.png

A imagem aparece quando o pacote e selecionado no /inventario.
